# Source reference

The project follows Chapter 20, "A Telecommunications Protocol," in Jim
Woodcock and Jim Davies, *Using Z: Specification, Refinement, and Proof* (1996).
The relevant printed pages are 321-329, corresponding to PDF pages 335-343 in
the copy used during review.

- [Source PDF](https://dsc.ufcg.edu.br/~dalton/bib/woodcock96.pdf)
- [Oxford publication record](https://www.cs.ox.ac.uk/publications/publication2249-abstract.html)
- [Extraction and interpretation notes](extraction_notes.md)

The local source PDF, extracted chapter text, and page images were used during
the review but are excluded from this public repository. References to these
files in historical review notes describe the original local workspace.
Use the source PDF for mathematical notation and layout.
